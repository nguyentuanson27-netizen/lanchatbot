# Fallback và các câu cần sửa

Run này không có fallback: 0/16 slots. Mười hai final model drafts được verifier PASS; hai NO_SEND trong model route thuộc checkout/intake do code thực sự phát tin, hai HANDOFF là xác nhận mua và yêu cầu nhân viên. Không coi bốn terminal này là fallback lỗi.

Ba actual replies vẫn NEEDS_EDIT dưới đây. Đây là vấn đề giọng/cách tư vấn, không phải ba verifier FAIL. Nguồn giá/tồn của partial-source được cố ý ngắt; không đòi model bịa dữ liệu hoặc hứa follow-up ngoài khả năng.
